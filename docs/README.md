# GDOM Documentation

GDOM is a DOM-inspired UI layer for Geometry Dash mods built with Geode.

This documentation describes the **GDOM MVP contract**, not only the exact implementation available today. That keeps the public docs stable while the remaining MVP work is completed.

Implementation state is tracked separately in [Status](status.md).
